## Dataset status

This is the preferred Jmail source for the directed project. It supersedes the older
7,764-row flat sender-recipient CSV as the primary Jmail input. The older file is retained
only for continuity with the accepted missingness-paper analysis.

Jmail distributes a structured derivative assembled from public House Oversight Committee,
Department of Justice, and Yahoo-account releases. It is not a collection of original `.eml`
files. Its source identifiers must therefore be preserved through all derived outputs.

## Raw record unit

One row is one parsed email message. The verified dataset contains 1,781,028 records.

Key fields:

- `id`: unique message identifier;
- `doc_id` and `message_index`: document/thread provenance;
- `sender`;
- `to_recipients`, `cc_recipients`, and `bcc_recipients`: recipient arrays encoded as JSON;
- `sent_at`;
- `account_email`, `email_drop_id`, and `release_batch`: source and release provenance;
- `epstein_is_sender`.

The slim release excludes email-body text, which is appropriate for the network study.

## Higher-order status

A unique message identifier and recipient arrays permit reconstruction of one-to-many email
events after explicit recipient-policy and deduplication decisions.

The primary event policy will be declared before analysis:

- tail: singleton sender;
- head: distinct To recipients plus, if retained, distinct Cc recipients;
- Bcc: retained separately and excluded from the primary public-network analysis unless a
  documented sensitivity analysis is approved.

## Supported targets

- Directed arc recovery: yes.

- Native-event recovery: conditional on message-level deduplication and recipient policy.
- Conditional role assignment: yes.

## Processing constraints

- Preserve this Parquet file unchanged.
- Do not commit it to Git.
- Preserve `id`, `doc_id`, `email_drop_id`, `release_batch`, and recipient-header fields in
  every intermediate message-level table.
- Audit malformed timestamps, missing or malformed recipient arrays, duplicate message IDs,
  repeated messages across release batches, and quoted-message artifacts before creating
  native events.
